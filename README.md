# CoEM: Empowering Long-Context Reasoning with Commit-on-Evidence Memory

**Submitted to ICLR 2027**

This is the official repository for **CoEM (Commit-on-Evidence Memory)**.

## Overview

CoEM is a memory framework for long-context reasoning that learns when to convert source evidence into compact memory facts. It combines:

- **Delayed commitment:** retaining unresolved source excerpts in a pending set under a fixed memory budget.
- **Evidence verification:** checking proposed memory facts against cited source evidence before committing them.
- **Step-level evidence rewards:** training memory decisions using both answer quality and intermediate verification feedback.
